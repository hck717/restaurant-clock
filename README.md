# 🍜 員工打卡系統 (Restaurant Clock-in System)

一個畀餐廳用嘅輕量打卡 App — 喺任何平板/手機瀏覽器直接開，純前端零後端，所有數據儲存喺裝置本身（localStorage）。

**即開即用網址：** <https://hck717.github.io/restaurant-clock/>

## ✨ 功能

| 功能 | 說明 |
|------|------|
| 員工登入 | 揀名 → 輸入個人密碼 → 進入打卡頁 |
| 上班 / 下班 | 大圓形按鈕，每位員工每日每項**只可以撳一次** |
| 即時工時 | 返緊工嗰陣即時計算「已做 X 小時 Y 分鐘」，每 30 秒自動更新 |
| 今日概覽 | 一眼睇晒邊個返緊工、已完成、未打卡 |
| 打卡記錄 | 今週 / 今個月 / 自訂日期範圍，顯示上下班時間同工時 |
| 管理員管理 | 加員工、刪員工、每人獨立設密碼 |
| 匯出 CSV | 一鍵匯出全部記錄，用 Excel 直接開到 |
| 全廣東話介面 | 建議所有文字都係粵語 |

## 🖥️ 點樣用

### 員工打卡

1. 喺登入頁揀自己個名
2. 輸入個人密碼（由管理員設定）
3. 撳 **「上班」** 開始返工，放工撳 **「下班」**
4. 每日只可以打一次上班、一次下班

### 管理員（首次設定）

1. 登入頁撳底部 **「管理員登入」**
2. 管理員密碼：`0000`（可以喺 `app.js` 最頂改）
3. **加入新員工**：輸入名 + 設定最少 4 位數字密碼
4. 搞掂之後撳「登出」，員工就可以自己打卡

### 數據備份

- 所有數據（員工 + 打卡記錄）儲存喺瀏覽器嘅 localStorage，部機唔刪網站資料就唔會消失
- 管理員頁有 **「匯出 CSV」**，得閒匯出一份做 backup 穩陣啲

## 📱 喺 iPad 用（推薦：加到主畫面）

1. 用 Safari 打開 <https://hck717.github.io/restaurant-clock/>
2. 撳底部 **分享**（↑ 箭嘴 icon）
3. 揀 **「加入至主畫面」**
4. 改個名做「打卡」，加入
5. 以後主畫面撳 icon，全螢幕運行，好似 App 咁用

> ⚠️ 注意：一定要喺**線上網址**開，唔好直接開 `index.html` 檔案（`file://` 會令數據存唔到）。
> 每次「加入至主畫面」前，請確認 Safari 睇緊嘅係最新版本（撳 **AA** → 更新網站 或重新載入）。

## ⚙️ 自訂設定

| 想改嘅嘢 | 喺邊度改 |
|----------|----------|
| 管理員密碼 | `app.js` 最頂 `const ADMIN_PIN = "0000"` |
| 餐廳名稱 / logo emoji | `index.html` 入面 `<h1>` 同 `.login-logo` |
| 主題顏色 | `style.css` 最頂 `:root` 變數 |

### GitHub Pages 快速做法

1. 開個 public repo
2. Settings → Pages → Source 揀 `main` / root
3. 完成，網址係 `https://<username>.github.io/restaurant-clock/`

## ⚠️ 注意事項

- **單機數據**：每一部裝置各有獨立數據庫，唔係雲端同步。如果得一部平板完全冇問題；想多部機共享數據就需要另外加後端。
- **密碼安全**：員工密碼係明文存喺瀏覽器，呢個係為咗內部管理方便，唔適合做高安全級別用途。
- **防誤刪**：清 Safari 網站資料或者刪 App 會刪走數據，記住定期「匯出 CSV」備份。
